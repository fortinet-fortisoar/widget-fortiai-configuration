# Overview

The *FortiAI* solution pack `v5.0.0` and earlier uses the **FortiAI Configuration** wizard to configure *FortiAI* within a FortiSOAR environment. The configuration process includes selecting an LLM Integration, such as FortiAI, and configuring the integration based on the FortiSOAR user's login ID. Additionally, you can modify the default selected LLM model.

For more information head to [FortiAI](https://github.com/fortinet-fortisoar/solution-pack-fortinet-advisor/blob/tree/release/5.0.0/README.md) solution pack documentation.
